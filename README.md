# GameSphere World Tour

Quiero que crees una página web de entretenimiento basada en una competición mundial de minijuegos.

La idea es que los usuarios entren en la web para jugar directamente desde el navegador y competir por conseguir la mayor cantidad de puntos posible. Todo el entretenimiento debe ocurrir dentro de la propia web.

Concepto principal

Cada usuario tendrá un perfil con:

🏆 Puntos totales

🔥 Racha de días jugando

🎯 Nivel

🌍 Posición en el ranking mundial

📊 Estadísticas de los diferentes minijuegos

La web tendrá muchos minijuegos cortos, rápidos y variados. Cada partida debería durar aproximadamente entre 30 segundos y 3 minutos.

Tipos de minijuegos

Quiero incluir juegos como:

Juegos de velocidad y reflejos

Juegos de memoria

Juegos de lógica

Juegos de estrategia sencillos

Juegos de encontrar diferencias o errores

Juegos de patrones

Juegos de rapidez mental

Otros minijuegos originales

Sistema de competición

Los jugadores ganarán puntos dependiendo de cómo jueguen. Habrá:

Un ranking mundial

Rankings diarios y semanales

Un sistema de niveles

Rachas por jugar varios días seguidos

Logros y medallas desbloqueables

Desafío diario

Cada día debe haber varios minijuegos o pruebas especiales que todos los jugadores puedan intentar. Los resultados servirán para competir en un ranking diario.

Diseño

Quiero un diseño moderno, muy llamativo y divertido, parecido a una plataforma de juegos moderna.

La página principal debe tener un botón grande de:

🎮 JUGAR AHORA

Al pulsarlo, el usuario puede empezar rápidamente una partida.

También quiero un menú con:

🎮 Jugar

🏆 Ranking

🔥 Desafío diario

🏅 Logros

👤 Perfil

La experiencia debe ser muy rápida y adictiva, para que una persona pueda entrar, jugar unos minutos y tener ganas de volver otro día para mejorar su puntuación y subir en el ranking.

Por ahora, crea una primera versión completamente funcional con varios minijuegos sencillos que se puedan jugar directamente en la web.
